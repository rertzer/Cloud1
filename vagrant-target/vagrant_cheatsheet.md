# Vagrant

## Commands

| #   | Command             | What it does                                  |
| --- | ------------------- | --------------------------------------------- |
| 1   | `vagrant init`      | Creates a new `Vagrantfile`                   |
| 2   | `vagrant up`        | Creates/starts the VM                         |
| 3   | `vagrant halt`      | Shuts down the VM                             |
| 4   | `vagrant reload`    | Restarts the VM, applying Vagrantfile changes |
| 5   | `vagrant ssh`       | Opens an SSH session into the VM              |
| 6   | `vagrant status`    | Shows the VM's current state                  |
| 7   | `vagrant suspend`   | Pauses the VM and saves its state             |
| 8   | `vagrant resume`    | Resumes a suspended VM                        |
| 9   | `vagrant destroy`   | Deletes the VM                                |
| 10  | `vagrant provision` | Runs provisioning scripts again               |
| 11  | `vagrant box add`   | Downloads/adds a VM box                       |
| 12  | `vagrant box list`  | Lists installed Vagrant boxes                 |
